    buyAndStakeKeyForSubdomain

    • buyAndStakeKeyForSubdomain(
          args: {
              domainName: string;
              options?: InputGenerateTransactionOptions;
              referrer?: AccountAddressInput;
              sender: Account;
              subdomainName: string;
              targetAddress?: AccountAddressInput;
              toAddress?: AccountAddressInput;
          },
      ): Promise<SimpleTransaction>

      Buy a key for a domain and stake it to claim a subdomain in one transaction. This is the primary way to register a subdomain on Movement.

      The price follows a bonding curve - use getKeyBuyPrice() to check the current price.

      Parameters

      • args: {
            domainName: string;
            options?: InputGenerateTransactionOptions;
            referrer?: AccountAddressInput;
            sender: Account;
            subdomainName: string;
            targetAddress?: AccountAddressInput;
            toAddress?: AccountAddressInput;
        }

        The arguments for the function.

        • domainName: string

          The parent domain name (e.g., "test" for "sub.test.move").

        • Optionaloptions?: InputGenerateTransactionOptions

          Optional transaction options.

        • Optionalreferrer?: AccountAddressInput

          Optional referrer address for fee sharing.

        • sender: Account

          The account buying and staking the key.

        • subdomainName: string

          The subdomain to claim (e.g., "sub" for "sub.test.move").

        • OptionaltargetAddress?: AccountAddressInput

          Optional address this subdomain will resolve to (defaults to sender).

        • OptionaltoAddress?: AccountAddressInput

          Optional address that will own this subdomain (defaults to sender).

      Returns Promise<SimpleTransaction>

      A transaction object to be signed and submitted.

      Example

      import { Movement, MovementConfig, Network, Account } from "@moveindustries/ts-sdk";

      const config = new MovementConfig({ network: Network.TESTNET });
      const movement = new Movement(config);

      async function runExample() {
        const alice = Account.generate();
        await movement.fundAccount({ accountAddress: alice.accountAddress, amount: 100_000_000 });

        // Buy a key and stake it to claim "mysubdomain.test.move"
        const txn = await movement.buyAndStakeKeyForSubdomain({
          sender: alice,
          domainName: "test",
          subdomainName: "mysubdomain",
        });

        const result = await movement.signAndSubmitTransaction({ signer: alice, transaction: txn });
        console.log("Subdomain claimed:", result.hash);
      }
      runExample().catch(console.error);
